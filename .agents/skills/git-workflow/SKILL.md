# Git ワークフロー

本スキルは、ブランチ作成からコミット、プルリクエスト作成、スカッシュマージ、後処理までの手順を定めます。

## 適用手順

1. **作業ブランチの作成**
   - Issue 番号を含む名前で作業ブランチを作成し、切り替えます。
   - ブランチ名例: `01-refactor-test-modules`
   - 作業ブランチ名を計画書に記録します。
   - コード修正を行う前に必ず作業ブランチに切り替えてください。

2. **コミット**
   - コミットメッセージは日本語で記述し、適切なプリフィックスおよびIssue番号を含めます。
   - コミットメッセージの形式:

     ```text
     feat: 簡潔な1行のタイトル (#12)

     - 詳細変更点1
     - 詳細変更点2
     ```

3. **プルリクエストの作成**
   - 計画書に基づく修正とテスト完了後、承認を得て `gh pr create` でプルリクエストを作成します。
   - PR本文にはクローズするIssue番号（例: `Closes #12`）を記載します。
   - プルリクエスト番号を計画書に記録します。

4. **スカッシュマージと後処理**
   - プルリクエストの承認を得たら、スカッシュマージを実行します。
   - マージ後、不要になった作業ブランチを削除します。
