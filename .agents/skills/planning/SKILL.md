# 計画書の作成と管理

本スキルは、作業開始前の計画書作成および進捗管理を行うための標準手順を定めます。

## 適用手順

1. **計画書の作成**
   - 作業開始前に `implementation_plan.md` を作成し、目的に応じた適切な構成で作業内容を整理します。
   - 変更対象のモジュール、検証手順、疑問点等を明記します。

2. **ユーザーの承認取得**
   - 計画書を作成したら必ずユーザーに提示し、承認（Proceed）を得てから以降の修正作業に進みます。

3. **追跡情報の記録**
   - 計画書内には以下の情報を適切なタイミングで記録・更新してください。
     - **Issue番号**
     - **作業ブランチ名**
     - **プルリクエスト番号**

4. **タスクリストでの進捗管理**
   - 計画書内にタスクリストを記述し、進捗に応じてステータスを更新します。
