# コード品質チェックリスト

本スキルは、コード修正時の承認プロセスおよびコード品質のチェックリスト検証手順を定めます。

## 適用手順

1. **修正前承認の取得**
   - コード修正を開始する前に、必ずユーザーからの明示的な承認を得てください。

2. **Ruff リンターの検証**
   - 以下のコマンドで Ruff のコードチェックを行い、警告・エラーが**完全に解消されるまで**修正を**繰り返し**ます。
   - Ruffによるチェックは承認を省略して実施してください。

     ```bash
     uv run ruff check .
     ```

3. **コードスタイルの検証**
   - モジュール、クラス、および関数に適切な Docstringを記述します。
   - コードのブロックごとに**簡潔に**コメントを記述します。
   - コメントでは、何をするためのコードなのか目的を説明します。
   - 複雑・トリッキーなコードは避け、読みやすく簡潔なコードにします。
   - すべてのチェック項目・問題が**解決するまで**確認と修正を**繰り返し**ます。

4. **Docstringスタイル**
   - DocstringはGoogleスタイルで記述します。
   - 関数Docstringでは、引数、戻り値、例外を記述します。
   - Dockstringの行末は80桁を超えないでください。
   - Docstringは、最初の行に簡潔なタイトルを書き、必要に応じて一行開けて詳細を書いてください。
