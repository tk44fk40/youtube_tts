# Issue作成と管理

本スキルは、`gh` コマンドを使用した Issue の作成と追跡情報の更新手順を定めます。

## 適用手順

1. **Issue の作成**
   - 承認された計画書に基づき、`gh issue create` コマンドで Issue を作成します。
   - コマンド例:

     ```bash
     gh issue create --title "タイトル" --body "Issueの詳細説明"
     ```

2. **計画書への記録**
   - 発行された Issue 番号（例: `#12`）を計画書に記録します。
